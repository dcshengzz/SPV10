Full Text Index Installation Steps :

1. Open "SQL Server Installation Center"
2. Click on "Installation and then on New SQL Server stand-alone installation"...
3. Navigate to SQL2017 folder and select and select the folder that ends with ENU
4. In the setup process just click next until you get to the Installation Type and then you check the "Add features to an existing instance of SQL Server..."
5. Click next to the "Feature Selection" and there you should pick "Full-Text and Semantic for search"
6. click next, next, next until the end.
